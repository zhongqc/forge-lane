# Sprint 历史与成员估点

用户追加：网页需要历史 Sprint 入口，以及当前 Sprint 按人统计 Story Points。直接实施，不包含此前暂缓的分析图表。

Backlog 提供“历史 Sprint”入口，列出已完成 Sprint，可选查看名称、目标、日期、结束时事项及成员点数。看板当前 Sprint 提供成员估点展开区域；数据不随看板个人/搜索筛选变化。按 Story/Task/Bug 聚合，排除 Epic/Subtask，避免父子重复计点。显示总点数、已完成点数、剩余点数、事项数、未估点数；null 与 0 分开，未分配独立一行，当前可访问成员即使0项也显示。

Sprint 完成事务在搬走未完成事项前写入独立 SprintSnapshot（每期一条 JSON 快照），包含事项 ID/key/title/type/status/负责人/estimate。快照不可变，后续修改负责人或点数不改写历史。已有历史期无快照仅展示目前仍关联的事项，并醒目标注不完整，不虚构旧数据。

新增 GET /api/sprints/:id/overview，复用项目权限和CLI范围验证。前端历史只读，可从事项链接打开实时详情。当前统计从服务端完整Sprint范围计算，避免板上过滤和分页造成错误。验证完成迁移前快照、后续编辑不影响历史、跨项目权限、0/null/小数/未分配/子任务排除及浏览器入口。
