# ADR 0003 — M1 本地任务验收

日期：2026-11-26；目标环境：macOS arm64。范围：M1 本地任务基础，执行能力继续受 ADR 0002 门禁约束。

## 实现范围

- Project + CODE/MANUAL/GROUP；项目内连续编号，UUID，UTC 时间与乐观版本。名称/标题/正文/验收标准/标签/枚举在 Core 最终校验。
- 固定状态看板，标题/编号搜索、优先级/标签/父组/状态筛选、归档筛选，列内排序和 Backlog/Todo 移动，拖拽有按钮等价入口。
- MANUAL Start/验收；GROUP 汇总、显式验收、活动子任务阻止取消；取消不级联。取消子任务可用独立成员命令移出组，不重开、不篡改终态需求。已取消且仍有父组的任务须先移出再归档。
- 叶子同项目无环依赖、单层父组；改变成员检查父子版本；已开始人工任务不能增加尚未完成的新依赖。CODE Start/Done 不允许用户绕过。
- 需求变更生成不可变修订；标签/排序/成员关系不生成需求修订。事务内写业务数据、幂等回执与活动。重复 requestId 返回原结果，内容变化拒绝，版本冲突保留草稿。
- Markdown 源码编辑和安全预览，禁原始 HTML，远程图片/链接不主动加载。组件采用 React 原生控件与少量自有样式，没有新增 UI 框架。
- 明确保存/取消、未保存离开提示、IME、Core 失联保留已加载界面与草稿；冲突提供最新内容比较及用户主动沿用最新版本重试。
- 全局外观/工具路径、项目名称/描述、按需 remote/默认分支/GitHub 身份与权限诊断；继承全局工具设置。环境检查有时限，不发模型请求。脱敏结果持久化并按配置版本失效。
- 本地 IPC 查询不依赖浏览器联网状态。初次环境检查可跳过；缺工具/未认证/网络错误不封锁本地任务管理。

独立审查已修复：取消成员无法移出、离线暂停 IPC、后台错误卸载草稿、项目/父组版本冲突无法原位恢复。补充修正跨列落在卡片上的拖拽传播，以及环境检测披露/配置缓存失效。没有为 CODE 编造执行状态或 PR。

最终验证：28 项单元/集成测试通过；7 项开发桌面场景通过；6 项真实安装包场景通过（开发 URL 测试跳过）；lint、format、typecheck、build 通过。`scripts/test-offline-migration.mjs` 使用包内生产迁移入口，在系统网络出站被禁止、PATH 无 Node 时通过首次建库、重复启动、M0 升级、备份和设置保留。外层 sandbox-exec 与 Chromium 自身沙箱冲突，因此完整 GUI 没有声称通过同一外层禁网测试；GUI 另以真实浏览器 offline 事件覆盖本地读写。开发包仍未签名/公证，实体净机验收和发布包优化属于 M5。当前 M0 的模型审批、中断、对话持久化恢复和扩展隔离尚未通过，不能把 M1 完成理解为可自动执行。
